# Sources and redistribution

- **BANC v888:** Bates, Phelps, Kim, Yang and collaborators, *Distributed control circuits across a brain-and-cord connectome*. [Nature paper](https://doi.org/10.1038/s41586-026-10735-w), [Harvard Dataverse deposit](https://doi.org/10.7910/DVN/7WTH1N), [BANC project](https://github.com/htem/BANC-project). The deposit specifies **CC BY 4.0**. The two release assets preserve the original input bytes used by these experiments. [experiments/data.json](experiments/data.json) contains their hashes and sizes. The metadata is an earlier pinned v888 snapshot; the mutable upstream metadata object has since changed. Downloading the current object does not reproduce these results.
- **FlyGym / NeuroMechFly:** [NeLy-EPFL/flygym](https://github.com/NeLy-EPFL/flygym), Apache-2.0. The pinned package supplies body assets and runtime code. The required `flygym_demo/complex_terrain` helpers and step assets are redistributed unchanged from the installed development environment in `vendor/`; [the license](vendor/LICENSE-flygym) is included. The simulation uses neural motor output; importing these helpers does not substitute a scripted gait for it.
- **FlyBody:** [TuragaLab/flybody](https://github.com/TuragaLab/flybody), Apache-2.0; Vaxenburg et al., [Nature 2025](https://doi.org/10.1038/s41586-025-09029-4). FlyGym supplies the body assets. The copied flight setup implements the published flight configuration; its original attribution remains in `simulator/lanes/A/fl2_flybody_lift.py`. [Apache-2.0 text](vendor/LICENSE-Apache-2.0).
- **Wingbeat pattern:** `simulator/lanes/A/fl2_assets/wing_pattern_fmech.npy`, redistributed unchanged from [TuragaLab/FlySuite](https://github.com/TuragaLab/FlySuite/blob/main/data/wing_pattern_fmech.npy), **MPL-2.0**. SHA-256: `f97b975ef1b5adbe42c208ea9665f3c37fa432914f56f3943f1697cdb090d1ce`. [License](vendor/LICENSE-FlySuite).
- **MuJoCo:** [google-deepmind/mujoco](https://github.com/google-deepmind/mujoco), Apache-2.0, installed as a pinned dependency.
- **Wet-lab measurements:** The Uploading Lab, measurement `MEAS-HACKATHON-VIDEO-20260912-R3`. Selected recordings made 12 September 2026; measurement revision 13 September 2026. The numeric inputs preserve the supplied exploratory, unreviewed status. Raw animal videos and personal filesystem paths are not bundled.

Original Uploading Lab experiment code is provided under the repository's MIT license. Third-party files and data retain the licenses listed above.

Installed dependency versions, declared licences and bundled licence texts are recorded in [provenance/dependency-licenses.json](provenance/dependency-licenses.json). FFmpeg is installed through ImageIO; its binary retains the licence supplied by its distributor.
