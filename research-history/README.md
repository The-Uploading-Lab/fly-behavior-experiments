# Research history

This archive preserves the 101 diary entries published on the lab website, dated August 5 through September 15, 2026, with their tracked figures and clips. Six website page snapshots are included. Files are copied byte for byte from the source revision recorded in `manifest.json`. The archive records the judgments and terminology used at the time; later corrections belong in the dated supplement below.

The diary is a historical source, not evidence that every described improvement survived later checks. In particular, historical counts of 188,508 “neurons” refer to model rows, including non-neuronal labels. Gait scores changed as the observers were corrected, so scores from different diary dates cannot be pooled.

The [later evaluation supplement](later-evaluations.md) links the archived comparisons to the [executable publication analyses](../publication/README.md). The [hackathon reproduction instructions](../README.md) and [October model specification](../model-review/README.md) describe different frozen builds.

## Using this archive

Each entry below is readable on GitHub. Local figure and clip files are in `diary/assets/`; original website media URLs are preserved. The HTML files in `pages/` are website fragments and retain their original styling and relative URLs. The [live diary](https://theuploadinglab.ai/fly/diary) supplies the site shell. Historical reproduction commands mention files from the development repository; only the commands in `publication/README.md` and the repository root README are supported by this release. This export is a snapshot, not the private repository’s complete Git history.
